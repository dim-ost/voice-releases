# Voice — загрузки

Официальные установщики **Voice** — мессенджера с голосовыми каналами, видео, демонстрацией экрана и играми.

**Сайт:** https://voice-chat.ru · **Веб-версия:** https://voice-chat.ru/@me

## Скачать последнюю версию

Откройте [последний релиз](https://github.com/dim-ost/voice-releases/releases/latest) и выберите файл для своей системы:

| Система | Файл |
| --- | --- |
| Windows (любая) | `Voice-Setup-<версия>.exe` |
| macOS, Apple Silicon (M1–M4) | `Voice-<версия>-mac-arm64.dmg` |
| macOS, Intel | `Voice-<версия>-mac-x64.dmg` |
| Linux | `Voice-<версия>-linux-x86_64.AppImage` |
| Android | `Voice-<версия>.apk` |
| iPhone (через Sideloadly) | `Voice-<версия>-unsigned.ipa` |

Установленное приложение для компьютера **обновляется само** — скачивает только изменившиеся части.

> Файлы `latest*.yml`, `latest-mac-patch.json`, `*.blockmap` и `*-patch.tar.gz` нужны для автообновления — скачивать их не нужно.

## macOS: первый запуск

Приложение пока не подписано сертификатом Apple, поэтому при первом запуске macOS может предупредить о неизвестном разработчике.
Откройте **Системные настройки → Конфиденциальность и безопасность** и нажмите «Всё равно открыть».
Перетащите Voice в «Программы» — оттуда он обновляется сам.
