# Промоматериалы Voice

Материалы публичного README в фирменной системе «Полутон»: точечный знак, фиолетовый `#5b3cff`, ночные чернила `#0a0817`, бумага `#f4f2ff`, геометрическая типографика.

- `voice-hero.png` — сгенерированная промообложка по фирменным ресурсам Voice.
- `voice-together.png` — сгенерированный завершающий баннер.
- `voice-chat.webp`, `voice-chess.webp`, `voice-watch.webp` — реальные снимки интерфейса с вымышленными демонстрационными данными из официальных материалов сайта.

Основа визуального направления: `landing/polyton.css`, `landing/src/brand.mjs`, `landing/og/default.png` и `client/public/logo-mark.png` из проекта Voice. Промобаннеры — иллюстрации; снимки интерфейса не сгенерированы.

Эти файлы — материалы бренда Voice. Публикация в репозитории не предоставляет отдельной лицензии на товарные обозначения или оформления.
